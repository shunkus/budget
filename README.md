# Budget Manager

A simple web application for managing personal budget.

## Features

- **Daily Budget**: Automatically adds a set amount to your budget every day
- **Expense Tracking**: Record expenses and deduct them from your budget
- **Budget Reset**: Reset your budget to today's daily budget amount
- **Authentication**: Simple login system with persistent session

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- localStorage (data persistence)

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the app.

## Deployment

Deploy to Vercel:

```bash
vercel
```

Or connect your GitHub repository for automatic deployments.
